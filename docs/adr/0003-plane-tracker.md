# Redmine as Ticket Tracker (formerly Plane.so)

We chose Redmine (self-hosted, open-source project management) as the ticket tracker over local markdown files, SQLite with a custom schema, GitHub Issues, or Plane.so. Redmine provides a REST API for work item CRUD with state management, built-in UI for ticket visualization, and self-hosts via Docker Compose — fitting the existing infrastructure model. Local markdown files are too fragile for programmatic state management by the orchestrator. GitHub Issues requires network access to a remote service. A custom SQLite-based tracker would add a bespoke front-end and API surface that Redmine already provides. Plane.so was the original choice but had unresolvable issues (POST /issues/ 404, unknown admin credentials). The `platform.tracker` adapter wraps Redmine's API behind the `Tracker` ABC, making the choice swappable later.
